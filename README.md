# Nexus Web & Digital — Portfólio Comercial da Agência

Repositório oficial contendo o portfólio da agência e demonstrações de projetos web de alta performance desenvolvidos para empresas, profissionais liberais e criadores digitais.

## Estrutura do Repositório

- `portfolio/` — Site principal da agência apresentando serviços, diferenciais e portfólio unificado.
- `projetos/` — Demonstrações funcionais divididas por segmentos comerciais:
  - `institucional-solar/` — Site institucional para prestadores de serviços / energia solar.
  - `landing-whatsapp-viagens/` — Landing page de alta conversão para captura de leads e WhatsApp.
  - `vendas-infoproduto/` — Página de vendas para cursos, mentorias e produtos digitais.
  - `clinica-estetica/` — Site elegante para clínicas de estética e saúde.
  - `imobiliaria-luxo/` — Portal imobiliário de alto padrão.
- `assets/` — Recursos visuais e imagens de apresentação.
- `documentacao/` — Guias de proposta comercial, pacotes de preços e estratégias de prospecção.

## Tecnologias Utilizadas

- **HTML5 Semântico**
- **Tailwind CSS (via CDN)** — Zero complexidade de build, carregamento instantâneo.
- **FontAwesome 6** — Ícones modernos.
- **Design Responsivo & Mobile-First** — Otimizado para qualquer dispositivo.

## Como Executar Localmente

1. Clone o repositório ou navegue até a pasta:
   ```bash
   cd portfolio-agencia-web
   ```
2. Abra o arquivo do portfólio ou qualquer projeto no seu navegador:
   ```bash
   xdg-open portfolio/index.html
   ```
